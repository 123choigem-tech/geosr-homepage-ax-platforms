# GeoSR Homepage / AX Platforms

GeoSR 홈페이지의 **18101 디자인 테스트 버전**을 보관하는 저장소입니다

## 범위

- 한영 전환을 지원하는 정적 HTML·CSS·JavaScript 홈페이지
- 대문 영상, AX Platform 갤러리, 조직도, 연구실적, 채용 및 문의 페이지
- 현재 화면에서 참조하는 이미지·로고·영상·글꼴과 글꼴 라이선스
- 개별 AX 플랫폼은 외부 링크로 연결되며 해당 플랫폼의 서버 코드·데이터는 포함하지 않음

운영 홈페이지와 18100 테스트 버전, 인증정보, 서버 설정, 내부 작업 문서 및 이전 디자인 실험 자료는 포함하지 않습니다

## 로컬에서 실행

영상 로딩에 `fetch()`를 사용하므로 `index.html`을 더블클릭하는 대신 HTTP 서버로 열어주세요

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8080/`을 열면 됩니다

Node.js 설치나 별도 빌드는 필요하지 않습니다

## 미디어와 연결 주소

- `assets/journey-autoplay-20260915/`의 MP4/WebM 및 1696/960 버전은 브라우저·화면 크기에 따른 대문 영상 소스입니다
- 플랫폼 화면은 이미지이며 접속 버튼은 기존 외부 서비스 주소를 사용합니다
- 일부 연결 주소는 임시 Cloudflare 주소이므로 해당 서비스가 종료되면 연결되지 않을 수 있습니다
- 이 저장소에 업로드하는 것만으로 현재 운영 홈페이지에 자동 배포되지는 않습니다

## 저작권·라이선스

글꼴 라이선스는 각 글꼴과 함께 포함했습니다 (`assets/` 및 `assets/fonts/`의 라이선스 파일 참고)

공개 저장소에 게시한다는 이유로 회사 로고·이미지·영상·소스 전체에 별도의 오픈소스 라이선스를 부여하지는 않습니다
제3자 자료의 이용 조건은 해당 권리자의 라이선스를 따릅니다
